# FigasOptimizer PRO License API

FastAPI service for FigasOptimizer PRO license activation and validation.

## Render settings

- Runtime: Python 3
- Build command: `pip install -r requirements.txt`
- Start command: `uvicorn main:app --host 0.0.0.0 --port $PORT`

## Required environment variables

Set these in Render Dashboard → your service → Environment:

- `FIGAS_ADMIN_TOKEN`: a long random secret used only for admin actions.
- `FIGAS_SIGNING_KEY`: the Ed25519 private key as base64, generated by the project's `tools/gen_license_keys.py`.
- `FIGAS_LICENSE_DB`: optional path to the SQLite database. On Render Free, the local filesystem is ephemeral; this does NOT provide durable storage. Use a persistent disk on a supported paid plan or migrate to a managed database before selling licenses.

Never commit `FIGAS_ADMIN_TOKEN` or `FIGAS_SIGNING_KEY` to GitHub, and never send them to customers.

## Routes

- `GET /health`
- `POST /licenses/activate`
- `POST /licenses/validate`
- `POST /admin/licenses` (requires `X-Admin-Token` header)
- `POST /admin/licenses/{license_key}/revoke` (requires `X-Admin-Token` header)

## Create a license

PowerShell example after deployment (replace the placeholder locally; do not share the token):

```powershell
$headers = @{ "X-Admin-Token" = "YOUR_ADMIN_TOKEN" }
$body = @{ duration_days = 365 } | ConvertTo-Json
Invoke-RestMethod -Uri "https://YOUR-SERVICE.onrender.com/admin/licenses" -Method Post -Headers $headers -Body $body -ContentType "application/json"
```

Omit `duration_days` for a license with no expiration date.

## Important before production

The public Ed25519 key embedded in the desktop app must correspond to `FIGAS_SIGNING_KEY`. Generate a new key pair if the matching private key is not available, then update `PUBLIC_KEY_B64` in `app/core/licensing/license_token.py` and rebuild the app. Keep the private key only in Render environment variables.
